# SCT_DA_4
Exploratory Data Analysis of a marketing campaign dataset to generate business insights, analyze customer behavior, and recommend marketing channels based on ROI.

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a marketing campaign dataset using Python. The goal is to analyze campaign performance, understand customer behavior, visualize the marketing funnel, and provide business recommendations based on ROI.

## Objective

- Clean and prepare marketing campaign data
- Analyze customer responses
- Perform Exploratory Data Analysis
- Visualize campaign performance
- Identify effective marketing channels
- Recommend better budget allocation strategies

## Tools Used

- Python
- Visual Studio Code
- Pandas
- Matplotlib
- Seaborn

## Dataset

The analysis uses the Marketing Campaign dataset containing customer information, campaign responses, and marketing performance details.

## EDA Process

Performed:

- Data loading
- Missing value analysis
- Duplicate removal
- Data cleaning
- Statistical analysis
- Data visualization

## Key Analysis

Analyzed:

- Customer conversion funnel
- Campaign response rate
- Marketing channel performance
- ROI-based insights

## Business Recommendations

Based on the analysis, marketing channels with higher conversion rates and better ROI should receive increased budget allocation.

## Project Outcome

Successfully completed an EDA-based business insights report to support data-driven marketing decisions.
